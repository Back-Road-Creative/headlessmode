{{/* system-docs shortcode — the honest documentation pointer for a system whose docs live in its repository rather than on this site. {{< system-docs name="keycut" >}} Looks the entry up in data/systems.json and renders one sentence pointing at the repository README — never a hand-typed URL, never a stand-in for docs that don't exist. A system with no repository (and no off-site link to fall back to) errors loudly: a Documentation section with nowhere to point is a page that should not call this shortcode. */}} {{- $name := .Get "name" -}} {{- if not $name }}{{ errorf "system-docs shortcode: missing required \"name\" attribute" }}{{ end -}} {{- $s := "" -}} {{- range site.Data.systems.systems -}} {{- if eq .name $name -}}{{- $s = . -}}{{- end -}} {{- end -}} {{- if not $s }}{{ errorf "system-docs: no data/systems.json entry named %q" $name }}{{ end -}} {{- $repo := "" -}} {{- if $s.repo -}}{{- $repo = $s.repo -}} {{- else if and $s.link (hasPrefix $s.link "http") -}}{{- $repo = $s.link -}} {{- end -}} {{- if not $repo }}{{ errorf "system-docs: %q has no repository to point at — write this page's Documentation section by hand" $name }}{{ end -}}

{{ $s.name }}’s documentation lives in its repository, next to the code it describes — the README is the manual.
