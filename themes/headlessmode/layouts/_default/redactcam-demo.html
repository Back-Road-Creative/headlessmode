Illustration: the plate filter in the ROAD_FOOTAGE preset

redactcam blurs faces, license plates and vehicle cabins in video, and checks the mask against a second vehicle detection pass before the video is encoded. A plate model also fires on road signs, so the preset drops boxes whose shape or size falls outside a window. The figure below draws that window and the ranges recorded for four kinds of object. It illustrates the preset's numbers; it is not a test of the filter on any footage.

This figure is drawn in your browser from a JSON file in this repository. Without JavaScript the chart and table below stay empty — the same numbers are readable directly in that JSON file.

Shaded region: boxes the plate gate accepts — the aspect and area window. Numbered rectangles are the ranges the preset's comments record for four kinds of road object.

The filter was tuned for that kind of footage and can fail on other footage, for example a plate at an unusual angle or a sign inside the plate window.
