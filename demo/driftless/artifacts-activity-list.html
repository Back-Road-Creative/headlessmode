Activity List

Documents artifact · ← Artifact catalog

What it is

The full list of individual pieces of work the project is broken into.

Why it matters

Without an enumerated list, nobody can say the plan actually covers everything.

What it looks like here

Not counted separately: it is exactly the count Activity Attributes already keeps, read rather than duplicated.

This product does not track this artifact against a real project's data — the enumeration is Activity Attributes' own count — read that.

Reached from a project's own process map, this page also shows what that project's own data says about this artifact.
