About

Headless Mode is a one-person software studio in Franklin, North Carolina. I build software for music practice, project and grant work, media production, and exploring rural places. The home page lists the products; each has its own page describing what it does and what access it has.

Studio and practice

My consulting practice is Back Road Creative. Headless Mode publishes the software; Back Road Creative scopes and runs the engagements that adapt these products to delivery work.

To ask about a product or a project, email hello@headlessmode.com or see Contact. Code and issues are on GitHub; shorter updates are on X.
